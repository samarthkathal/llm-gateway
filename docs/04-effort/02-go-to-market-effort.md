# Go-To-Market Effort Plan

## Phase 0 (weeks 0–6, parallel with build): design-partner recruitment

- Target: 8–10 conversations → 3–5 signed design partners (free/discounted year, weekly
  feedback, logo + case-study rights on success).
- Profile: 1k–10k-employee US/UK company, ≥2 LLM providers in production, named CISO or
  platform lead, no works council.
- Effort: founder time ~50%; zero marketing spend. The MVP scope in
  [`../08-mvp/01-mvp-plan.md`](../08-mvp/01-mvp-plan.md) is deliberately shaped to what a
  design partner can deploy in a day (SaaS, SSO, one config file for the gateway endpoint).

## Phase 1 (months 2–6): prove the double story

Success = one reference customer where, from the same deployment:
- the security team retired a shadow-AI worry (policy + audit evidence), and
- an executive quoted an intent insight in a real meeting ("we discovered X% of AI effort
  goes to legacy migration").
Everything in GTM converges on manufacturing that story; it is the wedge for both budgets.

## Phase 2 (months 6–12): repeatability

- Pricing hypothesis to test: platform fee ($15–25k) + per-seat ($3–6/user/mo) + insights
  tier upsell. Governance features gate the platform fee; insights gate the seat expansion.
- Sales motion: CISO/CIO-led, 60–90-day cycle target, security-review pack pre-built
  (SOC 2 Type I done by month 9 — see compliance roadmap in
  [`../03-legal/04-works-councils-and-global.md`](../03-legal/04-works-councils-and-global.md)).
- Content engine: EU-AI-Act-deadline countdown content (Dec 2027), shadow-AI governance
  guides, "AI ROI you can defend to the board" executive content.

## Phase 3 (year 2): EU preparation → entry

Gate: works-council pack legally reviewed + EU residency shipped + ISO 27001 underway.
Entry via DACH lighthouse customer with council pre-agreement (see
[`../03-legal/04-works-councils-and-global.md`](../03-legal/04-works-councils-and-global.md)).

## Metrics that matter (pre-Series-A scorecard)

| Metric | Month 6 target | Month 12 target |
|---|---|---|
| Design partners live | 3–5 | — |
| Paying tenants | 1–2 | 8–12 |
| ARR | $50–100k | $400–700k |
| Requests processed/mo | 1M | 20M |
| Insight-tier attach rate | — | ≥40% of tenants |
| Security-review pass rate | — | ≥80% without escalation |
| Logo churn | 0 | 0 (too early for any) |

## Budget envelope (pre-seed → seed)

- Months 0–6: ~$0 marketing spend (founder-led + content). Total burn dominated by 2–3
  salaries + infra (<$2k/mo at MVP volumes).
- Months 6–18 (post-seed): first GTM hire (founding AE or growth engineer), analyst
  relations, conference presence — ~$25–40k/mo GTM budget. See
  [`../07-financial/02-financial-model.md`](../07-financial/02-financial-model.md).
